DRM API 흐름

1. 재생 요청 LMS가 주문, 계약서, 수강권, 기기 수를 확인합니다.
2. 서명 토큰 영상 manifest URL과 짧은 만료 시간의 재생 토큰을 발급합니다.
3. DRM 라이선스 Widevine, FairPlay, PlayReady 라이선스 서버가 키를 발급합니다.
4. 추적 워터마크, IP, 기기, 챕터, 토큰 해시를 로그로 남깁니다.

필수 입장 계약서

강의 콘텐츠 보호 및 LMS 이용 동의

1. 계정과 수강권

수강권은 아임웹 결제가 확인된 주문 이메일과 LMS 계정 이메일이 일치할 때 활성화됩니다. 계정 대여, 공동 사용, 초대 링크 재배포는 허용되지 않습니다.

2. 강의 영상과 자료 보호

강의 영상, 자막, 자료, 과제 예시는 구매자 본인의 학습 목적으로만 사용할 수 있습니다. 녹화, 다운로드, 캡처물 공유, 재판매, 외부 배포는 제한됩니다.

3. 워터마크와 보안 기록

영상 재생 중 회원 이름, 이메일, 회원 ID가 화면에 표시될 수 있으며, 접속 기록과 재생 기록은 계정 보호와 유출 추적 목적으로 보관됩니다.

4. 과제와 피드백

제출한 과제와 피드백 요청 내용은 강의 운영, 학습 진도 확인, 답변 제공을 위해 사용됩니다. 보관 기간은 강의 종료 후 운영 정책에 따릅니다.
